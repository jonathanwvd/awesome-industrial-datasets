# Awesome Industrial Datasets

**🔗 Check the [HTML version](https://www.indatlas.com/datasets/) for better navigation.**

> [!NOTE]
> This list is generated from the datasets catalog of the [Industrial Atlas](https://www.indatlas.com/datasets/). Every entry links to its Atlas page, where you can search, filter and compare the datasets.

Welcome to the Awesome Industrial Datasets repository! This project aims to simplify the access to high-quality industrial datasets across various sectors such as chemical, mechanical, oil and gas, and more. These datasets are invaluable for researchers, engineers, and data scientists working on machine learning models and other analytical tasks that require real-world industrial data.

If you find this repository useful, please consider giving it a ⭐ to show your support!

## Tools

Libraries that help load datasets from this list:

- [bearing-datasets](https://github.com/VictorBauler/BearingDatasets): Python library that downloads public bearing and rotating-machinery fault datasets (including CWRU, Paderborn, XJTU-SY, FEMTO and IMS) from their original sources and converts them to a common metadata and Parquet format.
- [rul-datasets](https://github.com/tilman151/rul-datasets): Python library that provides benchmark datasets for remaining useful lifetime estimation (C-MAPSS, N-C-MAPSS, FEMTO and XJTU-SY) as PyTorch Lightning data modules with a shared API.

## Suggest a New Dataset

Thank you for helping improve this list. To suggest a dataset, open an issue with the "Suggest a dataset" template or write through the [Industrial Atlas contact page](https://www.indatlas.com/contact/). See [CONTRIBUTING.md](CONTRIBUTING.md) for the scope of the list and how entries are reviewed.

Before suggesting a dataset, please check that it is not already included in the catalog. In the issue, include:

- Dataset name.
- Official dataset page, repository, paper, or download link.
- Short description of the industrial domain and use case.
- Any known license, access restrictions, size, year, and annotation details.

Accepted datasets are added to the Industrial Atlas first and reach this list on the next update. The files in `json/` and `markdown/` and this README are generated, so pull requests that edit them by hand are not merged; open an issue instead.
