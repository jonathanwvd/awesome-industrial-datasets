# Industrial IoT Fault Detection Dataset

Table of 1000 machine sensor readings with vibration, temperature and pressure plus a fault label for no fault, bearing fault or overheating.

- **Domain:** Manufacturing
- **Modality:** Tabular
- **Task:** Fault diagnosis; Classification
- **Annotation:** Class label
- **Access:** Kaggle
- **Size:** 1000 entries
- **License:** CC0 and public domain

## Description

The Industrial IoT Fault Detection Dataset, also titled Industrial IoT Fault Detection Dataset for Predictive Maintenance in Automation, is a table of sensor data collected from machinery in an industrial automation environment. It comes as one CSV file, industrial_fault_detection_data_1000.csv.

Each of the 1000 entries records three sensor measurements that describe equipment health: vibration in mm/s, temperature in °C and pressure in bar. Two derived features, RMS vibration and mean temperature, are added; the publisher notes that they help separate potential fault types.

A Fault Label column gives the fault type per entry, coded 0 for no fault, 1 for bearing fault and 2 for overheating. The data is released under CC0 1.0.
