# PSPLIB

Library of ProGen-generated benchmark instances and solutions for single-mode, multi-mode and resource investment project scheduling problems.

- **Domain:** Cross-industrial
- **Modality:** Problem instances
- **Task:** Scheduling and optimization
- **Source Type:** Synthetic
- **Access:** Direct download
- **Year:** 1996

## Description

The Project Scheduling Problem Library (PSPLIB) holds benchmark instances for resource-constrained project scheduling. Its reference is the 1996 article "PSPLIB - A project scheduling library" by R. Kolisch and A. Sprecher in the European Journal of Operational Research, Vol. 96, and the instances were generated with the standard project generator ProGen.

Data sets cover the resource-constrained project scheduling problem (RCPSP), its multi-mode variant (MRCPSP), both with minimal and maximal time lags (RCPSP/max and MRCPSP/max), the resource investment problem with time lags (RIP/max) and RCPSP with time-dependent resource capacities. Each directory holds the instances of a problem together with their solutions.

Downloads are sorted into single-mode, multi-mode and other problems, then by number of jobs, and each archive holds one file per instance. For example, j30.sm.tgz contains 480 single-mode problems with 30 jobs. Users can also upload their own solutions to the library.
