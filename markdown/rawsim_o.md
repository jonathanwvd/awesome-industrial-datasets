# RAWSim-O

Discrete event-based simulation framework for Robotic Mobile Fulfillment Systems, built for adding and testing new methods for their decision problems.

- **Domain:** Logistics and retail
- **Modality:** Simulator
- **Task:** Simulation and control
- **Source Type:** Simulation
- **Access:** Code repository
- **Year:** 2018
- **License:** GPL

## Description

RAWSim-O is a discrete event-based simulation framework for Robotic Mobile Fulfillment Systems, written by Marius Merschformann with Lin Xie, Hanyi Li and other contributors as part of the RMFS project initiated by Prof. Lin Xie. It was described in Logistics Research in 2018 and builds on the Alphabet Soup framework.

The framework is meant for researching the effects of the several decision problems that arise when such a system runs, and it is built so that new decision methods can be added for each of them. It offers 2D and 3D views, simulates larger and multi-level instances, shows details of path planning engines and renders heatmaps of where robots were over time.

The Visual Studio solution generates a default instance and runs it from the visualization project, and some functions need GnuPlot. The code is released under the GNU General Public License, version 3 or later.
