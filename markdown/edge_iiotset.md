# Edge-IIoTset

IoT and IIoT cyber security dataset from a seven-layer testbed, with normal traffic from over 10 device types and fourteen labelled attacks for centralized and federated learning.

- **Domain:** OT security
- **Asset / Process:** Control systems and networks
- **Modality:** Network traffic; Tabular
- **Task:** Intrusion detection
- **Annotation:** Class label
- **Source Type:** Lab or testbed
- **Access:** IEEE DataPort
- **Size:** 1.48 GB
- **Year:** 2022

## Description

Edge-IIoTset is a cyber security dataset of IoT and Industrial IoT (IIoT) applications by Mohamed Amine Ferrag, Othmane Friha, Djallel Hamouda, Leandros Maglaras and Helge Janicke, described in IEEE Access in April 2022. The testbed spans seven layers, from IoT and IIoT perception through edge, fog, software-defined networking, blockchain and network functions virtualization to cloud computing.

Normal traffic comes from more than 10 device types, among them distance, flame, heart rate, pH, soil moisture and water level sensors and a Modbus device. Attack traffic covers fourteen attacks in five threat groups: DoS/DDoS, information gathering, man in the middle, injection and malware, including ransomware, SQL injection, XSS and port scanning.

Two selected sets are prepared for machine and deep learning intrusion detection, using 61 features chosen from 1176 candidates, for centralized and federated learning. Free academic use is granted; commercial use requires asking the lead author.
