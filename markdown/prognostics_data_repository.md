## Description

The Prognostics Data Repository collects data sets donated by universities, agencies and companies, limited to data that can be used to develop prognostic algorithms. Most entries are time series running from a nominal state to a failed state. NASA publishes it, and the PHM Society website mirrors it.

Its 21 listed data sets range from lab experiments to simulation. They include algae raceways, CFRP composite panels under tension-tension fatigue, milling inserts, bearings from the IMS center and from FEMTO-ST, Li-Ion batteries, IGBT accelerated aging, MOSFET thermal overstress and capacitor electrical stress, a trebuchet, and two turbofan engine degradation sets generated with C-MAPSS, along with the PHM08 challenge data.

Most data sets come with a ZIP download and a data set citation; for some of the others, NASA asks users to request the data by e-mail. Publications are asked to acknowledge the repository and the donors, and the data is used at the user's own risk.
