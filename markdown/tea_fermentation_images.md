# Tea Fermentation Image Dataset

Six thousand images of black tea during fermentation, taken in a tea factory in Kenya and shared for comparing algorithms.

- **Domain:** Food and beverage
- **Modality:** Image
- **Task:** Other
- **Source Type:** Real production
- **Access:** Mendeley Data
- **Size:** 6000 images

## Description

The Tea Fermentation Image Dataset is a collection of 6000 photographs of black tea in the fermentation stage of processing. All of them were taken inside a working tea factory in Kenya.

The record is on Mendeley Data, where the current release is version 3, published in 2021. The images are packed in two zip archives that can be downloaded from the record page.

The contributors set their own conditions in the description. The images are meant only for comparing algorithms, which they treat as fair use of the images and metadata, must not be redistributed, and anyone who uses them should cite the contributors. These conditions are narrower than the CC BY 4.0 license shown on the portal, so read the record's terms before any use other than comparing algorithms.
