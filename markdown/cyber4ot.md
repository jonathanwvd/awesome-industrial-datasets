## Description

Cyber4OT is a set of network packet traces recorded in a test-bed environment of an operational technology (OT) network. It was prepared by researchers at Warsaw University of Technology and published on Zenodo in November 2024 as version 1.0.0.

The traces contain normal activity of the OT network as well as a complete network attack. During the recorded attack, the attacker carries out full network reconnaissance, then disconnects a legitimate Modbus TCP connection and hijacks a PLC device. The release has 96 trace files with more than 4.25 million packets in total, and a ReadMe.txt file gives a short description of the content of each trace file.

The traces are distributed as a single archive, Cyber4OT.zip, under the CC BY-NC 4.0 license, which limits reuse to non-commercial purposes.
