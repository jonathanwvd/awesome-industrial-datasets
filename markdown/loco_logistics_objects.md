# LOCO

37,988 images from five logistics environments, 5,593 of them hand-annotated with 152,421 labels for forklifts, pallet trucks, pallets, small load carriers and stillages.

- **Domain:** Logistics and retail
- **Modality:** Image
- **Task:** Object detection
- **Source Type:** Real production
- **Access:** Direct download
- **Size:** 37,988 images, 5,593 annotated
- **Year:** 2020
- **License:** CC0 and public domain

## Description

LOCO, short for Logistics Objects in Context, is a scene understanding dataset aimed at detecting objects specific to logistics. Its images were taken with low-cost cameras while walking through logistics settings. It accompanies a paper by Mayershofer, Holm, Molter and Fottner at the IEEE International Conference on Machine Learning and Applications (ICMLA) 2020, and Christopher Mayershofer maintains it.

The current release holds 37,988 images from 5 logistics environments. Of these, 5593 were annotated by hand, yielding 152,421 annotations over classes that include forklifts, pallet trucks, pallets, small load carriers and stillages. The annotations follow the COCO format in one file, rgb/loco-all-v1.json, with separate files for each subset.

The annotated images and a further set of unannotated images are offered as separate downloads. The work is dedicated to the public domain under CC0 1.0, so it can be copied, modified and distributed, also for commercial purposes, without permission.
