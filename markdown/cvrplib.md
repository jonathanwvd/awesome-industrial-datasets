# CVRPLIB

Library of CVRP and VRPTW test instances grouped into sets from the vehicle routing literature, from Christofides et al. (1969) to the XL and XTW sets of 2026.

- **Domain:** Logistics and retail
- **Modality:** Problem instances
- **Task:** Scheduling and optimization
- **Access:** Direct download

## Description

CVRPLIB is a library of test instances for vehicle routing, organised into named sets taken from published work. Most sets are CVRP instances, and a second group covers VRPTW. Each instance can be downloaded on its own, and the instance table also reports an upper bound (UB) and an Opt column for every entry.

The CVRP sets are A, B and P (Augerat et al., 1995), E (Christofides et al., 1969), F (Fisher, 1994), M and CMT (Christofides et al., 1979), tai (Rochat et al., 1995), Golden (Golden et al., 1998), Li (Li et al., 2005), X (Uchoa et al., 2017), AGS (Arnold et al., 2019), DIMACS (2021), XML (Queiroga et al., 2022) and XL (Queiroga et al., 2026).

The VRPTW sets are Solomon (1987), Homberger (Homberger et al., 2005) and XTW (Uchoa et al., 2026). Instance names run from small cases such as A-n32-k5 to large ones such as XTW-n1001.
