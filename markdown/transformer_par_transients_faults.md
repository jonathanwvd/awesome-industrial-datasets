# Transients and Faults in Power Transformers and Phase Angle Regulators

PSCAD/EMTDC simulations of internal faults in power transformers and phase angle regulators in a 5-bus system, alongside six other power system transients.

- **Domain:** Energy and power
- **Asset / Process:** Power grids and plants
- **Modality:** Time series
- **Task:** Fault diagnosis; Classification
- **Source Type:** Simulation
- **Access:** IEEE DataPort
- **Size:** 88128 internal fault files and 12780 transient files
- **Year:** 2020

## Description

This simulated dataset covers internal faults in power transformers and phase angle regulators (PAR) within a 5-bus interconnected power system. Its authors, Pallav K. Bera, Can Isik and Vajendra Kumar, released it on IEEE DataPort in 2020.

Besides the internal faults, it includes six other power system transients: ferroresonance, capacitor switching, switching of non-linear loads, magnetising and sympathetic inrush, and external faults that saturate the current transformers. The archive has 88128 internal fault files and 12780 files of the other disturbances. All cases were simulated in PSCAD/EMTDC and the outputs are text files.

A readme PDF delivered with the data describes every file. The files sit in one ZIP archive and are open access to any user logged in with an IEEE account; membership is not required.
