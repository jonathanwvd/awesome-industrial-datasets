# RIAWELC

24,407 radiographic weld images of 224x224 pixels in four classes, lack of penetration, porosity, cracks and no defect, for weld defect classification.

- **Domain:** Manufacturing
- **Asset / Process:** Welding
- **Modality:** X-ray and CT
- **Task:** Classification
- **Annotation:** Class label
- **Size:** 24,407 radiographic images
- **Year:** 2022

## Description

RIAWELC is a collection of radiographic images for classifying weld defects. Benito Totino, Fanny Spagnolo and Stefania Perri introduced it at the Interdisciplinary Conference on Mechanics, Computers and Electrics (ICMECE 2022), held on 6-7 October 2022 in Barcelona, Spain.

The set holds 24,407 radiographic images of 224x224 pixels at 8 bits, digitised as PNG files. Each image belongs to one of four classes: lack of penetration (LP), porosity (PO), cracks (CR) or no defect (ND).

The README also asks users to cite a second paper by Stefania Perri, Fanny Spagnolo, Fabio Frustaci and Pasquale Corsonello on classifying welding defects with a convolutional neural network, which it lists as in press in Manufacturing Letters, published by Elsevier. The images are hosted in a GitHub repository.
