# Maintenance Action Recommendation

Event codes and parameter snapshots from industrial equipment, released for the 2013 PHM Society challenge on recommending maintenance actions.

- **Domain:** Cross-industrial
- **Modality:** Tabular
- **Task:** Classification
- **Annotation:** Class label
- **Source Type:** Real production
- **Access:** Competition
- **Size:** 4 CSV files
- **Year:** 2013
- **Publisher:** PHM Society
- **Benchmark:** Yes

## Description

Maintenance Action Recommendation is the data of the 2013 PHM Society Conference Data Challenge, which focused on recommending maintenance actions, a common problem in industrial remote monitoring and diagnostics. The data was generated by an industrial piece of equipment; for proprietary reasons the organisers do not describe the equipment or its domain.

Four CSV files are provided. Train - Case to Problem (2.25 KB) links each case to a problem number that stands for a maintenance action. Train - Nuisance Cases (80.43 KB) lists cases that were not instructive enough to act on. Train - Case to Events and Parameters (960.13 MB) and Test - Case to Events and Parameters (653.75 MB) hold the event codes and parameter snapshots for each case.

Entrants submit one recommendation per case, or "none". The score is the number of outputs minus incorrect and nuisance outputs. The competition closed on 14 August 2013.
