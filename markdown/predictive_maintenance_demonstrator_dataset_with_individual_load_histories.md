# Predictive maintenance demonstrator dataset with individual load histories

Fatigue test bench demonstrator in which notched steel specimens fail according to individual load histories, with separate training and testing data for virtual sensing.

- **Domain:** Materials and metrology
- **Modality:** Time series
- **Task:** Regression; RUL and prognostics
- **Source Type:** Lab or testbed

## Description

This dataset is a laboratory demonstrator for predictive maintenance in which component failure follows individual load histories. Its sensor setup uses simple notched steel specimens clamped between two servo-hydraulic cylinders of a fatigue test bench. In many real applications, time to failure is measured in years.

The demonstrator is built as a use case for virtual sensing, where unmeasured physical quantities are predicted from the available measurement data and virtual sensors stand in for quantities that are hard to measure. It comes with independent training and testing data, so it can be used to develop and benchmark predictive maintenance and virtual sensing algorithms.
