# Datasets for aluminum electrolysis process, coal chemical process, and CSTR

Three labelled process datasets, from aluminum electrolysis, coal carbonization and a simulated stirred-tank reactor, for operating condition classification and fault diagnosis.

- **Domain:** Chemical and process
- **Asset / Process:** Chemical process units
- **Modality:** Tabular
- **Task:** Classification; Fault diagnosis; Process monitoring
- **Annotation:** Class label
- **Source Type:** Mixed
- **Access:** IEEE DataPort
- **Publisher:** Kangle Fan

## Description

This IEEE DataPort collection brings together three process datasets for analysing operating conditions.

The aluminum electrolysis data covers four conditions: normal operation, siphoning of liquid aluminum, anode replacement and the anode effect, a gas film that insulates the anode and makes the cell voltage jump. The coal carbonization data has six classes, from normal operation through minor deviation, under-coking, poor coal quality and over-coking to a severe combined anomaly; its variables describe coking parameters, coal properties and coke quality.

The third set is a simulated continuous stirred-tank reactor with normal operation and twelve faults: catalyst decay, fouling of the heat transfer surface, seven sensor shifts and three disturbances in concentration and temperature. The files are Excel and CSV. Electrolysis classes are given by file name, coking classes by a label column, and the reactor files are headerless CSVs whose class mapping is explained in the README and supplementary material. Suggested uses include process monitoring, fault diagnosis and class-incremental learning.
