# Tennessee Eastman Reference Data for Fault-Detection and Decision Support Systems

Extended Tennessee Eastman simulations with 28 process faults in 6 operating modes, each run 500 times, plus setpoint changes and mode transitions.

- **Domain:** Chemical and process
- **Asset / Process:** Chemical process units
- **Modality:** Time series
- **Task:** Fault diagnosis; Process monitoring
- **Source Type:** Simulation
- **Size:** 28 faults × 6 modes × 500 runs
- **Year:** 2021
- **License:** CC0 and public domain
- **Publisher:** Technical University of Denmark

## Description

This dataset is an extended set of simulations of the Tennessee Eastman process. Christopher Reinartz, Murat Kulahci and Ole Ravn published it in 2021 at the Technical University of Denmark, together with a paper on an extended Tennessee Eastman simulation dataset for fault detection and decision support systems.

It simulates 28 process faults in each of 6 operating modes, and every fault is repeated 500 times with different random seeds. Further runs cover setpoint changes and transitions between the operating modes. Each simulation lasts 100 hours and is sampled every 3 minutes.

The record is tagged for statistical process monitoring, fault diagnosis and decision support, and it is released under CC0.
