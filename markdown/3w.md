## Description

The 3W Dataset is the core of the 3W Project, which Petrobras launched publicly on May 30, 2022 to support machine learning approaches for detecting and classifying undesirable events in offshore oil wells. The project is led by the company's Flow Assurance department and its CENPES research center, and its Well Integrity department has taken part in governance since May 2024.

The dataset is built from instances drawn from three different sources, each containing undesirable events that occur in oil wells; specialised professionals label the instances. It is stored as multiple Parquet files in subdirectories of the repository, with its version kept in a separate file; Petrobras plans to supplement it with more instances from time to time.

The 3W Toolkit, a Python 3 package in the same repository, generates dataset overviews and standardises experiments that compare machine learning methods. The data files are licensed under CC BY 4.0 and the code under Apache 2.0.
