# MVTec ITODD

Industrial 3D object detection and pose estimation dataset with 28 objects in 3,500 labeled scenes, each observed by five sensors.

- **Domain:** Robotics and automation
- **Modality:** Image; 3D point cloud; Multimodal
- **Task:** Object detection; Pose estimation
- **Size:** 3,500 labeled scenes
- **License:** CC BY-NC-SA
- **Publisher:** MVTec

## Description

MVTec ITODD (MVTec industrial 3D object detection dataset) is a public dataset from MVTec for 3D object detection and pose estimation. It focuses on industrial settings and applications.

The dataset covers 28 objects and 3,500 labeled scenes that contain instances of these objects. Every scene is observed by five sensors: two 3D sensors and three grayscale cameras. MVTec publishes further information on the dataset in a PDF document.

MVTec ITODD belongs to the group of datasets used in the BOP (Benchmark for 6D Object Pose Estimation) challenge. The data is released under CC BY-NC-SA 4.0, so commercial use is not allowed, and MVTec asks to be contacted when it is unclear whether an application falls under the non-commercial clause.
