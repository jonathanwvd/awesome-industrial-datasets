# Turning Dataset for Chatter Diagnosis Using Machine Learning

Accelerometer, microphone and tachometer signals from lathe turning tests on aluminium, with time series tagged by chatter state, from no-chatter to chatter.

- **Domain:** Manufacturing
- **Asset / Process:** CNC machining and tool wear
- **Modality:** Vibration; Audio; Time series
- **Task:** Classification
- **Annotation:** Class label
- **Source Type:** Lab or testbed

## Description

This dataset holds sensor signals from cutting tests in which an Aluminum 6061 workpiece is turned on a 33 cm (13 inch) engine lathe, using a titanium nitride coated insert of 0.04 cm radius on an S10R-SCLCR3S boring bar. Michigan State University and Technische Universitat Chemnitz are the institutions behind it.

Signals come from a laser tachometer, a microphone, a tri-axial accelerometer and a pair of perpendicular single-axis accelerometers. Besides the raw data of every sensor, one channel of the tri-axial accelerometer is also supplied as conditioned and tagged data. Four tags are used; three of them are no-chatter, intermediate chatter and chatter.

Four cutting configurations are set by the stickout distance, which is the length between the back face of the tool holder and the heel of the boring rod: 5.08, 6.35, 8.89 and 11.43 cm. Each was run at several combinations of rotational speed and depth of cut. The documents give these combinations, the number of tagged time series per stickout length, a photo of the setup and a short note on the tagging algorithm.
