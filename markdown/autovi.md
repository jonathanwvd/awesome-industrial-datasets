# Automotive Visual Inspection Dataset (AutoVI)

Images from Renault Group automotive production lines with intentionally created defects, for unsupervised anomaly detection under real line conditions.

- **Domain:** Manufacturing
- **Modality:** Image
- **Task:** Anomaly detection
- **Source Type:** Real production
- **Access:** Zenodo, Dataverse or Figshare
- **Size:** 3,950 images
- **Year:** 2024
- **License:** CC BY-NC-SA
- **Publisher:** Renault Group and Université de technologie de Compiègne
- **Benchmark:** Yes

## Description

AutoVI is an image dataset recorded on Renault Group's automotive production lines and built jointly with the Roberval and Heudiasyc laboratories of the Université de technologie de Compiègne. Its stated purpose is to serve as a scientific benchmark for unsupervised anomaly detection under genuine production conditions, with changes in brightness and lighting on moving components.

The release holds 3,950 images, split into 1,530 for training and 2,420 for testing, delivered as six archives named engine wiring, pipe clip, pipe staple, tank screw, underbody pipes and underbody screw. According to the publishers, every defect shown was made deliberately for this release and fixed once photographed, and Renault Group experts did the labelling.

Evaluation code is published in a separate repository. The data is licensed under CC BY-NC-SA 4.0; the authors ask to be contacted about commercial use.
