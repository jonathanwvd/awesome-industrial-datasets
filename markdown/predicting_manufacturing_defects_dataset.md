# Predicting Manufacturing Defects Dataset

Synthetic tabular data built for teaching defect prediction, with a binary target that separates low-defect from high-defect production.

- **Domain:** Manufacturing
- **Modality:** Tabular
- **Task:** Classification; Quality prediction
- **Annotation:** Class label
- **Source Type:** Synthetic
- **Access:** Kaggle
- **License:** CC BY

## Description

This synthetic dataset models factors that influence defect rates in a manufacturing environment. It was generated for educational purposes and is an original dataset owned by Rabie El Kharoua.

Each record combines production volume and cost, supplier quality and delivery delay, defect rate and quality score, maintenance hours and downtime, inventory turnover and stockout rate, worker productivity and safety incidents, energy consumption and efficiency, and additive process time and material cost. Production volume, for example, ranges from 100 to 1000 units per day. The target, DefectStatus, is 0 for low defects and 1 for high defects.

The task is binary classification of the defect status. Defect instances are over-represented, so the classes are imbalanced. The data ships as one CSV file under CC BY 4.0.
