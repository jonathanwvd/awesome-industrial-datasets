## Description

PCAD is a dataset for visual anomaly detection on industrial assembly groups. The images were acquired with a specialized, reproducible hardware setup that captures assembly groups of varying complexity in different poses, and the dataset includes structural and semantic anomalies as well as variations in pose and lighting conditions.

It was introduced with the paper "PCAD: A Real-World Dataset for 6D Pose Industrial Anomaly Detection" by Maack, Thun, Liang, Tercan and Meisen at the WACV 2025 Workshops, which also evaluates several state-of-the-art anomaly detection models on the data. The work argues for using multi-component CAD models as a source of 3D information for anomaly detection in assembly inspection.

The code repository from the University of Wuppertal links to the data files, which include the final dataset, a lighting-variation set, synthetic data and the raw acquisition data together with the generation pipeline.
