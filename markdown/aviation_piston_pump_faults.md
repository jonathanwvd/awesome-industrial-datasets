# Experimental Data for Aviation Piston Pumps

Pressure, flow, vibration, temperature, speed and torque signals from tests of an aviation piston pump in normal and several fault modes.

- **Domain:** Aerospace and defense
- **Asset / Process:** Pumps, compressors and fans
- **Modality:** Time series; Vibration
- **Task:** Fault diagnosis
- **Access:** Mendeley Data
- **Year:** 2025
- **License:** CC BY

## Description

This dataset holds measurements from simulated tests of one model of aviation piston pump, run in normal operation and in several fault modes. It was shared on Mendeley Data by Jiming Ma in 2025.

The tests follow a standardised procedure designed for the pump, with operating conditions such as variable rotational speed and pressure and flow rate sweeps. Recorded channels include pressure, flow rate, vibration, temperature, rotational speed and torque. The fault modes target key pump components such as the servo piston, the swashplate slide rail and the pressure regulation valve.

The released archive holds processed data that keeps the valid segments. The data suits fault diagnosis of aviation piston pumps, and it is shared under CC BY 4.0.
