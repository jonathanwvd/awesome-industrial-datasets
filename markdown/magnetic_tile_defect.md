# Magnetic Tile Defect

Surface images of magnetic tiles covering six common defect types, each with pixel-level ground truth for defect saliency detection.

- **Domain:** Materials and metrology
- **Asset / Process:** Surfaces and textures
- **Modality:** Image
- **Task:** Defect detection; Defect segmentation
- **Annotation:** Pixel mask
- **Access:** Code repository
- **Year:** 2018

## Description

The Magnetic Tile Defect dataset is a collection of images of magnetic tile surfaces assembled for the paper "Saliency of magnetic tile surface defects". It is distributed through the GitHub repository abin24/Magnetic-tile-defect-datasets, created in 2018, and the authors ask anyone who uses the images in research to cite that paper.

The images show six common kinds of magnetic tile defects. For every image the defect regions are labelled with pixel-level ground truth, so the data serves saliency detection, where a model has to mark which pixels of a tile surface belong to a defect.

A companion repository, Saliency-detection-toolbox, collects saliency detection models for surface defects: the authors' MCue model and 14 other models.
