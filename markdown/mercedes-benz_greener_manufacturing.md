# Mercedes-Benz Greener Manufacturing

Train and test tables of Mercedes-Benz car feature permutations, framed around predicting the time each configuration needs on the test bench.

- **Domain:** Manufacturing
- **Asset / Process:** Vehicles and fleets
- **Modality:** Tabular
- **Task:** Regression
- **Annotation:** Scalar target
- **Access:** Kaggle

## Description

Mercedes-Benz Greener Manufacturing is a tabular dataset about the testing of cars on Mercedes-Benz production lines. Every car configuration passes a testing system that checks its safety and reliability before it reaches the road, and the many possible feature combinations make speeding up that testing complex and time-consuming.

Each row represents one permutation of features of a Mercedes-Benz car, paired with the time that car needs to pass testing. The data comes as two CSV files, train.csv and test.csv.

The accompanying text frames the data as a challenge: reduce the time cars spend on the test bench by predicting the testing time from the configuration. Faster testing is meant to lower carbon dioxide emissions without relaxing the manufacturer's standards.
